# 💱 Currency Converter

A clean, lightweight currency converter built with **HTML, CSS and vanilla JavaScript**. It fetches **live exchange rates** from a public currency API and instantly converts between currencies, with country flags that update as you switch.

## ✨ Features
- Real-time exchange rates via an external REST API (Fetch API, async/await)
- Convert between INR, USD, EUR and JPY
- Dynamic country flags that update with the selected currency
- Input validation with a safe default amount
- Loading status message and error handling for failed or unavailable requests
- One-click reset to default values
- Clean, centered card-style UI
